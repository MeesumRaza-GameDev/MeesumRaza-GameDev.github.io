About the Project

Development overview

Brainrot Rush: Sand Escape is a Unity-based casual arcade game built around fast-paced movement, obstacle avoidance and chaotic brainrot-style gameplay.

The game focuses on creating short and entertaining gameplay sessions where players must react quickly, navigate through hazards and escape challenging sand-based environments.

I worked on the gameplay systems and interactions required to turn the core concept into a playable mobile experience.
